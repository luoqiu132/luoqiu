# MONITOR 原逻辑界面版 v1.1.1

本次按用户要求改为**直接修改并保存所选汇总模板**。没有结果文件路径，不生成新结果工作簿，不调用额外的 SaveAs 或格式转换。执行前请保存并关闭该模板已有的 Excel 窗口，避免文件被占用为只读。

**需要已安装的 Microsoft Excel 桌面版；不需要安装 Python。**

按九份原始 Python 脚本执行。界面只提供观测文件、汇总模板、日期、公式来源行、基准位置等输入，执行日志显示在界面中。计算语句保持原样，写表由本机 Excel 处理，不使用此前的通用 XLS 公式转换器，不再解析钢筋计模板中无关的 L3 等公式。

## 下载及启动

1. 点击绿色 Code → Download ZIP，完整解压到本机文件夹。
2. 关闭旧程序，双击 **MonitoringDesk.exe**。此版已直接包含 exe，无需合并分卷。
3. 确认右上角显示 **v1.1.1**，选择观测数据、汇总模板、日期和原代码参数，点击“执行并保存汇总模板”。
4. “打开 Excel”用于在 Excel 中直接查看和编辑原文件；编辑后保存并关闭模板窗口，再运行计算。

九份脚本的所有算术表达式通过逐项 AST 比对保持不变；已用 COM 协议替身验证钢筋计只写原代码指定列、不解析无关公式。打包后的脚本及 COM 运行库检查、导航和日历检查通过。构建环境未安装 Excel，因此未声称已验证实际 Excel 工作簿写入，实际模板请在安装 Excel 的目标电脑核对。

二次开发源工程保留九份原脚本及界面输入适配层，可继续修改原计算代码并重打包。本版本不使用旧兼容版的计算插件。

`examples` 是合成演示数据，不是工程标定参数。`release-info.json` 和 `SHA256SUMS.txt` 提供版本、大小及校验值。
